# Task 3: 공과 물리 (벽, 막대)

## 참조
- FR-4, FR-5, FR-6, FR-20 (발사 전 대기 부분)

## 선행 task
- Task 2

## 구현 기능 목록
- 공 엔티티: 위치, 속도 벡터, 반지름, 기본 속도 상수화
- 대기 상태: 공이 막대 위에 놓이고 막대를 따라 움직임
- 발사: space를 누르면 왼쪽 또는 오른쪽(랜덤) 위로 45도로 발사
- 벽(좌/우/상) 충돌 반사
- 막대 충돌: 맞은 위치에 따라 반사각 변화 (가운데는 수직에 가깝게, 가장자리는 비스듬히), 속력 유지
- 반사 후 각도가 수평 기준 15도 미만이면 15도로 보정 (벽·블록 반사 공통 함수)
- 바닥으로 나간 공 감지 (제거 처리는 Task 5)
- 빠른 속도에서도 막대를 뚫지 않도록 이동을 나눠 충돌 검사 (터널링 방지)
- 공 렌더링

## 완성 조건
- [ ] 공이 막대 위에서 시작하고 막대를 움직이면 같이 움직인다.
- [ ] space를 누르면 공이 왼쪽 또는 오른쪽 위로 45도 각도로 발사된다.
- [ ] 공이 좌/우/상 벽에 부딪히면 반사된다.
- [ ] 막대 가운데에 맞으면 거의 수직으로, 가장자리에 맞으면 비스듬하게 튕긴다.
- [ ] 어떤 반사 뒤에도 공의 각도가 수평 기준 15도 이상이다.
- [ ] 공 속도를 크게 올려도 막대를 통과하지 않는다.
- [ ] 반사각 계산, 15도 보정, 충돌 판정에 대한 단위 테스트가 통과한다.
