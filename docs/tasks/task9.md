# Task 9: 아이템 효과

## 참조
- FR-14, FR-15, FR-16, FR-29

## 선행 task
- Task 8

## 구현 기능 목록
- 효과 상태 관리 모듈(순수 로직): 공 속도 상태(기본/2배/절반), 막대 길이 상태(기본/2배/절반)와 남은 시간, 점수 + 남은 시간
- 공 분산: 현재 공마다 방향이 조금씩 다른 공 2개를 추가해 3배로 만든다. 최대 6개까지만 증가
- 공 속도 +/-: 지속 시간 없음, 누적되지 않음, 반대 아이템을 먹으면 기본 속도. LIFE 상실, 스테이지 클리어 시 기본 속도로 초기화
- 막대 길이 +/-: 10초 지속, 반대 아이템을 먹으면 기본 길이(상쇄), 같은 아이템 재습득 시 10초로 갱신, 만료되면 원래 길이로 복귀
- 점수 +: 10초 동안 블록 점수 200점, 재습득 시 10초 갱신, 만료 시 복귀
- LIFE 상실, 스테이지 클리어 시 막대 길이와 점수 + 효과는 남은 시간 동안 유지
- 효과 타이머는 게임 시간 기준이며 pause 중에는 흐르지 않음
- 남은 효과가 보이도록 간단한 표시 (HUD에 아이콘과 남은 시간)

## 완성 조건
- [ ] 공 분산을 먹으면 공이 3배가 되고, 6개를 넘지 않는다.
- [ ] 공 속도 +를 먹으면 2배, 다시 먹어도 더 빨라지지 않는다. 이후 -를 먹으면 기본 속도로 돌아간다. (반대도 동일)
- [ ] LIFE를 잃거나 스테이지를 클리어하면 공 속도가 기본으로 초기화된다.
- [ ] 막대 길이 +/-가 10초 후 원래 길이로 돌아오고, 반대 아이템은 상쇄되며, 재습득 시 10초로 갱신된다.
- [ ] 점수 + 중에는 블록당 200점이 들어오고 10초 뒤 100점으로 돌아온다.
- [ ] LIFE를 잃어도 막대 길이와 점수 + 효과가 남은 시간 동안 유지된다.
- [ ] pause 중에는 효과 남은 시간이 줄지 않는다.
- [ ] 효과 상태 전이와 타이머 갱신에 대한 단위 테스트가 통과한다.
