# Task 1: 프로젝트 초기화와 게임 골격

## 참조
- PRD 비기능 요구사항: 호환성(16:9, 창 크기 스케일링), 기술(Canvas 2D, React, Vitest), 성능(60fps)
- 직접 대응하는 FR 없음 (모든 task의 기반)

## 선행 task
- 없음

## 구현 기능 목록
- Vite + React + TypeScript 프로젝트 생성
- Vitest 설정 및 샘플 테스트 1개
- 논리 해상도 1280x720 캔버스를 만들고, 창 크기에 맞춰 16:9 비율을 유지하며 스케일링(남는 영역은 여백 처리)
- 고정 시간 간격 update와 requestAnimationFrame render로 구성된 게임 루프
- 상수 파일(constants): 해상도, 그리드(12x8), LIFE(3), 점수(100), 드롭 확률(0.2), 지속 시간(10초), 최대 공 개수(6) 등
- 게임 로직은 React와 분리된 순수 TypeScript 모듈로 구성하는 디렉터리 구조

## 완성 조건
- [ ] `npm run dev`로 실행하면 캔버스가 화면에 표시된다.
- [ ] 창 크기를 바꿔도 16:9 비율이 유지되고 캔버스가 찌그러지지 않는다.
- [ ] 게임 루프가 일정한 간격으로 update를 호출하고, 임시 도형(예: 움직이는 사각형)이 부드럽게 그려진다.
- [ ] `npm run test`가 통과한다.
- [ ] `npm run build`가 오류 없이 끝난다.
