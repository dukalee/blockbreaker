## 개요
블록깨기 게임

## 목표
맵의 하단의 막대를 좌우로 움직여 벽에 부딫히면 방향을 바꿔 이동하는 공을 튕겨 맵 상단의 모든 벽돌을 부시는 것이 목표이다.

## 기능 요구사항
막대 (플레이어)
- 마우스 또는 키보드 좌우 버튼으로 막대를 이동시킬 수 있다. 
- 키보드를 누르고 있으면 연속적으로 이동하게 하도록 한다. 
- 마우스와 키보드 입력이 동시에 있으면 마지막 입력을 우선한다.
- pause 중에는 공, 아이템, 지속 아이템 타이머 등 게임의 모든 동작이 정지한다.

벽돌 
- 매 스테이지마다 랜덤으로 맵의 상단에 배치된다.
- 색상은 알록달록하게 여려 색을 사용한다.
- 메탈 블록도 소수 존재한다. 이 블록들은 깨지지 않는다.
- 강화 블록이 존재한다. 이 블록들은 2번 공에 부딫혀야지만 깨진다. 
- 벽돌이 깨질때 마다 점수가 100점씩 올라간다. 강화 블록은 완전히 깨질 때만 100점이 올라간다.

공
- 초기에는 막대 위에서 시작한다.
- 발사 전에는 공이 막대를 따라 움직인다.
- 스페이스바를 누르면 공이 왼쪽 또는 오른쪽 위로 45도 각도로 발사되며 게임이 시작된다.
- 공이 발사된 이후는 막대에 부딫히면 튕겨 나온다.
- 공은 벽, 막대, 블록에 부딫히면 튕겨 나와 방향을 바꾼다. 이에 대한 물리 법칙을 적용하라.
- 공이 막대에 맞을 때는 맞은 위치에 따라 반사각이 달라진다. (가운데는 수직에 가깝게, 가장자리는 비스듬히) 반사 후 공의 각도는 수평 기준 최소 15도를 보장한다. (벽·블록 반사도 동일)

아이템
- 랜덤으로 벽돌을 깨면 아이템이 위에서부터 중력으로 인해 천천히 떨어진다.
- 벽돌이 깨질 때 20% 확률로 아이템이 드롭되며, 6종은 동일한 확률로 나온다. (드롭 비율은 이후 조정 가능)
- 아이템이 막대에 닿으면 습득하고, 놓치면 화면 밖으로 사라진다.
- 지속 시간이 있는 아이템을 이미 사용 중에 다시 습득하면 10초로 갱신된다.
- 아이템의 종류는 다음과 같다.
  - 공 분산 아이템 : 공이 3배로 증가한다. (1개였다면 3개로, 3개였다면 9개로, 각 1개의 공이 x3이 된다.)
  - 공 속도 + 아이템 : 공의 이동 속도가 2배 증가한다. (이 아이템을 추가적으로 획득한다 해도 더 빨라지지 않는다.)
  - 공 속도 - 아이템 : 공의 이동 속도가 절반으로 느려진다. (이 아이템을 추가적으로 획득한다 해도 더 느려지지 않는다)
  - 공 속도 아이템은 지속 시간이 없다. 속도가 + 상태에서 - 아이템을 먹거나 - 상태에서 + 아이템을 먹으면 기본 속도로 돌아간다.
  - 공 속도 아이템 효과는 LIFE를 잃거나 스테이지를 클리어하면 기본 속도로 초기화된다.
  - LIFE를 잃거나 스테이지를 클리어해도 막대 길이와 점수 + 효과는 남은 시간 동안 유지되고, 낙하 중인 아이템도 계속 떨어진다. (공 속도만 초기화된다.)
  - 공의 개수는 최대 6개이다. 분산 아이템으로 6개를 넘게 되면 6개까지만 늘어난다.
  - 막대 길이 +/- 아이템은 서로 상쇄된다. + 상태에서 - 아이템을 먹거나 - 상태에서 + 아이템을 먹으면 기본 길이로 돌아간다. 같은 아이템을 다시 먹으면 10초로 갱신된다.
  - 막대 길이 + 아이템 : 막대의 길이가 2배 증가한다. (이는 10초동안 지속된다.)
  - 막대 길이 - 아이템 : 막대의 길이가 절반으로 줄어즌다. (이는 10초동안 지속된다.)
  - 점수 + 아이템 : 깨는 블록의 점수가 2배 증가한다. 즉 블록당 200점이다. (이는 10초동안 지속된다.)
- 지속력이 있는 아이템은 시간이 종료된 후, 원상태로 돌아간다.

## 게임 규칙
- 공은 총 3개가 주어진다. (이걸 LIFE라고 표현한다.)
- 공이 막대 아래쪽으로 떨어지면 LIFE가 한개 깎인다. 공이 여러 개일 때는 모든 공이 떨어져야 LIFE가 한개 깎인다.
- 즉, 3개의 LIFE (공)에 대해서, 3번 막대 아래로 떨어지면 게임이 종료된다.
- 게임이 종료되면 GAME OVER 화면에 최종 점수가 표시되고, space를 누르면 title로 돌아간다. (최고 점수는 저장하지 않는다.)
- 한 스테이지의 모든 블록을 깨면, 다음 스테이지가 시작된다. (깨지지 않는 메탈 블록은 제외한다.)
- 각 스테이지의 블록 배치는 랜덤이다. (많을수도 있고, 적을수도 있다.) 96칸 중 40~70%를 채운다.
- 스테이지가 올라갈수록 난이도가 점진적으로 오른다. 공의 기본 속도가 빨라지고, 메탈 블록과 강화 블록의 비율이 늘어난다.
  - 스테이지마다 공 기본 속도가 5%씩 증가한다. (최대 2배)
  - 스테이지마다 메탈 블록과 강화 블록의 비율이 각각 3%p씩 증가한다. (메탈 블록 최대 10%, 강화 블록 최대 30%) 스테이지 1은 메탈·강화 블록 0%에서 시작한다.
- 스테이지 시작시에는 막대 위에 공이 있는채로 (space 바를 누르면 발사) 시작한다.

## 화면 구성
- 16:9비율을 사용한다.
- 논리 해상도는 1280x720이며, 창 크기에 맞춰 비율을 유지한 채 스케일링한다.
- 블록 그리드는 12열 x 최대 8행이며, 스테이지마다 랜덤으로 일부 칸만 채운다.

[초기 화면]
- 우주 배경의 arcade 스러운 title 화면을 구성한다.
- press space to start라는 문구가 반짝반짝하게 빛나고 있다.

[게임  화면] 
- 맵의 하단에는 막대, 상단에는 블록들이 있다.
- 맵의 우측 상단에는 pause 버튼이 있다. pause 버튼을 누르면 restart, EXIT 버튼이 있다.
- EXIT버튼을 누르면 title로, restart를 누르면 1 스테이지부터 다시 시작한다. restart 시 점수 0, LIFE 3, 모든 효과가 초기화된다.
- ESC 키로도 pause를 열고 닫을 수 있다.
- 브라우저 탭이 비활성화되면 자동으로 pause 된다.
- pause 메뉴에는 볼륨 슬라이더가 있다.
- pause 버튼 옆에 음소거 토글 버튼이 있으며, 키보드 M 키로도 음소거할 수 있다.
- 맵 상단의 좌측에는 Stage 번호와 그 밑에 score 가 주어진다.

## 사운드
- 효과음과 BGM을 포함한다.
- 효과음은 다음 8종이다.
  - 공 발사
  - 공이 벽 또는 막대에 충돌
  - 블록 파괴
  - 강화 블록 또는 메탈 블록 타격
  - 아이템 습득
  - LIFE 상실
  - 스테이지 클리어
  - 게임 오버
- BGM: title 화면과 게임 화면
- 음원 파일 없이 Web Audio API로 코드에서 합성한다.
- 음소거 버튼과 볼륨 슬라이더를 제공한다. (UI 위치는 화면 구성 참고)
