# Task 2: 입력과 막대

## 참조
- FR-1, FR-2, FR-3

## 선행 task
- Task 1

## 구현 기능 목록
- 키보드 입력 상태 추적: 좌우 방향키 keydown/keyup (누르고 있는 동안 연속 이동)
- 마우스 입력: 마우스 x 좌표를 논리 좌표(1280x720)로 변환해 막대 중심에 반영
- 마지막 입력 우선: 마우스 이동과 키 입력 중 가장 최근 입력이 막대를 제어
- 막대 엔티티: 화면 하단 위치, 좌우 벽 안쪽으로 이동 범위 제한, 기본 크기 상수화
- 막대 렌더링

## 완성 조건
- [ ] 좌/우 방향키를 누르고 있으면 막대가 끊김 없이 연속 이동하고, 떼면 멈춘다.
- [ ] 마우스를 움직이면 막대가 마우스 x 좌표를 따라간다. 창 크기가 달라져도 위치가 일치한다.
- [ ] 마우스를 움직인 뒤 방향키를 누르면 키보드가, 다시 마우스를 움직이면 마우스가 막대를 제어한다.
- [ ] 막대가 좌우 벽 밖으로 나가지 않는다.
- [ ] 입력 우선순위 로직에 대한 단위 테스트가 통과한다.
