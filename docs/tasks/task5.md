# Task 5: LIFE, 스테이지 진행, 난이도

## 참조
- FR-17, FR-18 (상태 전이 부분), FR-19, FR-20, FR-21

## 선행 task
- Task 4

## 구현 기능 목록
- LIFE 3개 관리: 공이 여러 개일 때는 모든 공이 바닥으로 나가야 LIFE 1 감소
- LIFE를 잃으면 막대 위에 새 공을 놓고 대기 상태로 복귀 (공 속도 초기화 훅 제공: Task 9에서 연결)
- LIFE가 0이면 게임 오버 상태로 전환
- 스테이지 클리어 판정: 메탈을 제외한 모든 블록이 깨지면 다음 스테이지 시작
- 스테이지 시작 시 막대 위에 공이 있고 space로 발사
- 난이도: 스테이지마다 공 기본 속도 +5%(최대 2배), 메탈·강화 비율 각각 +3%p (메탈 최대 10%, 강화 최대 30%), 스테이지 1은 0%에서 시작
- 새 게임 시작 함수: 점수 0, LIFE 3, 스테이지 1로 초기화 (restart와 title 시작에서 재사용)

## 완성 조건
- [ ] 공이 바닥으로 나가면 LIFE가 1 줄고 막대 위에 새 공이 놓인다.
- [ ] 공이 여러 개일 때 하나만 나가면 LIFE는 줄지 않는다. (공 여러 개 상태는 단위 테스트로 검증)
- [ ] LIFE가 0이 되면 게임 오버 상태가 된다.
- [ ] 메탈 블록만 남기고 모두 깨면 다음 스테이지가 시작된다.
- [ ] 스테이지 1은 메탈·강화 블록이 없고, 이후 스테이지에서 비율과 공 속도가 규칙대로 증가하며 상한을 넘지 않는다.
- [ ] 스테이지 번호 → 난이도 값 계산과 LIFE 감소 규칙에 대한 단위 테스트가 통과한다.
