# Task 11: BGM과 음소거, 볼륨 UI

## 참조
- FR-24 (pause 메뉴의 볼륨 슬라이더), FR-26, FR-28

## 선행 task
- Task 10

## 구현 기능 목록
- BGM 합성: title용, 게임용 두 곡을 간단한 시퀀서로 반복 재생 (Web Audio API)
- 화면 전환에 맞춰 BGM 전환 (title <-> 게임), GAME OVER와 pause 시 처리 정리
- pause 버튼 옆 음소거 토글 버튼
- M 키로 음소거 토글
- pause 메뉴의 볼륨 슬라이더 (마스터 볼륨 제어)
- 음소거 상태와 볼륨 값 유지 (화면 전환 사이)

## 완성 조건
- [ ] title 화면과 게임 화면에서 서로 다른 BGM이 반복 재생된다.
- [ ] 음소거 버튼과 M 키로 모든 소리(효과음, BGM)가 꺼지고 다시 켜진다.
- [ ] pause 메뉴의 볼륨 슬라이더로 볼륨이 조절되고 효과음과 BGM에 모두 적용된다.
- [ ] 화면을 전환해도 음소거 상태와 볼륨이 유지된다.
- [ ] pause 중 BGM 동작(일시정지 또는 유지)이 일관되게 동작한다.
