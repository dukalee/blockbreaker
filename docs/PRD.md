# PRD: Block Breaker (벽돌깨기)

## 1. 배경

- 현재 문제: 벽돌깨기 게임을 처음부터 새로 만드는 프로젝트이며, 기존 구현은 없다.
- 관련 문서/이슈: `docs/Spec.md` (게임 규칙의 원본), `CLAUDE.md` (프로젝트 규칙)

## 2. 대상 사용자

- 주요 사용자: 데스크톱 웹 브라우저에서 가볍게 즐기는 일반 플레이어
- 보조 사용자: 없음

## 3. 범위

이번 작업에 포함:

- [ ] 막대, 공, 블록(일반/강화/메탈)과 충돌·반사 물리
- [ ] 아이템 6종(공 분산, 공 속도 +/-, 막대 길이 +/-, 점수 +)
- [ ] 스테이지 진행, 점수, LIFE, 게임 오버, 난이도 상승
- [ ] title / 게임 / GAME OVER 화면, pause 메뉴(restart, EXIT, 볼륨 슬라이더), 음소거
- [ ] 효과음 8종과 BGM (Web Audio API 합성)
- [ ] 16:9 화면 (논리 해상도 1280x720, 창 크기에 맞춰 스케일링)

이번 작업에 포함하지 않음:

- [ ] 최고 점수 저장, 랭킹
- [ ] 서버, 계정, 멀티플레이
- [ ] 모바일 터치 입력

## 4. 사용자 흐름

1. 사용자가 title 화면에서 space를 누른다.
2. 시스템은 1스테이지를 시작하고, 막대 위에 공이 놓인 상태로 대기한다.
3. 사용자가 space를 누르면 공이 발사되고, 막대를 움직여 공을 튕긴다.
4. 시스템은 블록 충돌 시 점수를 올리고, 확률적으로 아이템을 떨어뜨린다.
5. 사용자가 아이템을 막대로 받으면 시스템이 효과를 적용한다.
6. 메탈 블록을 제외한 모든 블록을 깨면 시스템이 다음 스테이지를 시작한다.
7. 공을 모두 놓치면 LIFE가 1 줄고, 막대 위에 새 공이 놓인다.
8. LIFE가 0이 되면 GAME OVER 화면에 최종 점수가 표시되고, space를 누르면 title로 돌아간다.
9. 게임 중 pause 버튼을 누르면 게임이 멈추고 restart, EXIT, 볼륨 슬라이더가 나타난다.

## 5. 기능 요구사항

막대
- FR-1: 마우스 또는 키보드 좌우 키로 막대를 이동한다.
- FR-2: 키를 누르고 있는 동안 연속 이동한다.
- FR-3: 마우스와 키보드가 동시에 입력되면 마지막 입력을 우선한다.

공
- FR-4: 공은 막대 위에서 시작하고, space를 누르면 왼쪽 또는 오른쪽 위로 45도 각도로 발사된다.
- FR-5: 공은 벽, 막대, 블록에 부딪히면 물리 법칙에 따라 튕긴다.
- FR-6: 막대에 맞은 위치에 따라 반사각이 달라진다. (가운데는 수직에 가깝게, 가장자리는 비스듬히) 반사 후 공의 각도는 수평 기준 최소 15도를 보장한다. (벽·블록 반사도 동일)

블록
- FR-7: 스테이지마다 12열 x 최대 8행 그리드(96칸)의 40~70%를 랜덤으로 채워 배치한다.
- FR-8: 일반 블록은 여러 색을 사용하고 1번 맞으면 깨진다.
- FR-9: 강화 블록은 2번 맞아야 깨진다.
- FR-10: 메탈 블록은 깨지지 않는다.
- FR-11: 블록이 완전히 깨질 때마다 100점을 얻는다. (강화 블록은 완전히 깨질 때만)

아이템
- FR-12: 블록이 깨지면 20% 확률로 아이템이 드롭되고, 6종은 같은 확률이다. 드롭 비율은 조정할 수 있어야 한다.
- FR-13: 아이템은 중력으로 천천히 떨어지고, 막대에 닿으면 습득하며, 놓치면 사라진다.
- FR-14: 지속 아이템을 사용 중에 다시 습득하면 지속 시간이 10초로 갱신된다.
- FR-15: 아이템 종류와 효과는 아래와 같다.

| 아이템 | 효과 | 지속 |
|--------|------|------|
| 공 분산 | 공이 3배로 늘어난다. 최대 6개. | 즉시 |
| 공 속도 + | 공 속도 2배 | 없음 (LIFE 상실, 스테이지 클리어 시 초기화) |
| 공 속도 - | 공 속도 절반 | 없음 (LIFE 상실, 스테이지 클리어 시 초기화) |
| 막대 길이 + | 막대 길이 2배 | 10초 |
| 막대 길이 - | 막대 길이 절반 | 10초 |
| 점수 + | 블록 점수 2배 (200점) | 10초 |

- FR-16: 공 속도 +/-는 누적되지 않으며, 반대 아이템을 먹으면 기본 속도로 돌아간다. 막대 길이 +/-는 서로 상쇄되어, 반대 아이템을 먹으면 기본 길이로 돌아간다.
- FR-29: LIFE를 잃거나 스테이지를 클리어해도 막대 길이와 점수 + 효과는 남은 시간 동안 유지되고, 낙하 중인 아이템도 계속 떨어진다. (공 속도만 초기화된다.)

게임 진행
- FR-17: LIFE는 3개이다. 공이 여러 개일 때는 모든 공이 막대 아래로 떨어져야 LIFE가 1개 깎인다.
- FR-18: LIFE가 0이 되면 GAME OVER 화면에 최종 점수를 보여주고, space를 누르면 title로 돌아간다.
- FR-19: 메탈 블록을 제외한 모든 블록을 깨면 다음 스테이지가 시작된다.
- FR-20: 스테이지 시작 시 막대 위에 공이 있고, space로 발사한다. 발사 전에는 공이 막대를 따라 움직인다.
- FR-21: 스테이지마다 공 기본 속도가 5%씩 증가하고(최대 2배), 메탈·강화 블록 비율이 각각 3%p씩 증가한다. (메탈 최대 10%, 강화 최대 30%) 스테이지 1은 메탈·강화 블록 0%에서 시작한다.

화면
- FR-22: title 화면은 우주 배경의 아케이드풍이며 "press space to start"가 반짝인다.
- FR-23: 게임 화면은 하단에 막대, 상단에 블록이 있고, 좌측 상단에 Stage 번호와 그 아래 score를 표시한다.
- FR-24: 우측 상단에 pause 버튼이 있다. pause 메뉴에는 restart(1스테이지부터 다시, 점수 0·LIFE 3·모든 효과 초기화), EXIT(title로)와 볼륨 슬라이더가 있다. ESC 키로도 pause를 열고 닫을 수 있다.
- FR-25: pause 중에는 공, 아이템, 지속 아이템 타이머 등 모든 동작이 정지한다.
- FR-26: pause 버튼 옆에 음소거 토글 버튼이 있고, M 키로도 음소거할 수 있다.
- FR-30: 브라우저 탭이 비활성화되면 자동으로 pause 된다.

사운드
- FR-27: 효과음 8종을 재생한다. (공 발사, 벽·막대 충돌, 블록 파괴, 강화·메탈 블록 타격, 아이템 습득, LIFE 상실, 스테이지 클리어, 게임 오버)
- FR-28: title 화면과 게임 화면에 BGM을 재생한다.

## 6. 비기능 요구사항

- 성능: 공 최대 6개, 블록 최대 96개 상황에서도 끊김 없이 동작한다. (목표 60fps)
- 접근성: 해당 없음. 단, 음소거 버튼과 볼륨 슬라이더를 제공한다. (추가 접근성 요구는 정해지지 않음)
- 보안: 해당 없음. 서버 통신과 사용자 데이터가 없다.
- 로깅/모니터링: 해당 없음. 개발 중 디버깅용 콘솔 로그 정도만 사용한다.
- 호환성: 최신 데스크톱 브라우저(Chrome, Edge, Firefox). 창 크기가 달라져도 16:9 비율을 유지한다.
- 사운드 정책: 브라우저 자동 재생 정책에 맞춰 첫 사용자 입력 이후 재생한다.
- 기술: 게임 영역은 Canvas 2D로 렌더링하고, title·pause·HUD 등 UI는 React로 구현한다. 단위 테스트는 Vitest를 사용한다.

## 7. 수용 기준

- [ ] Given 막대 위에 공이 있을 때, When space를 누르면, Then 공이 왼쪽 또는 오른쪽으로 발사된다.
- [ ] Given 공이 막대 가장자리에 맞을 때, When 반사되면, Then 가운데에 맞을 때보다 비스듬한 각도로 튕기되 수평 기준 15도 이상이다.
- [ ] Given 강화 블록이 있을 때, When 공이 1번 맞으면, Then 블록은 남고 점수는 변하지 않으며, 2번째에 깨지고 100점이 오른다.
- [ ] Given 메탈 블록이 있을 때, When 공이 맞으면, Then 블록은 깨지지 않는다.
- [ ] Given 공이 3개일 때, When 공 분산 아이템을 먹으면, Then 공이 6개가 되고 이후에는 더 늘지 않는다.
- [ ] Given 공 속도가 2배인 상태에서, When 공 속도 - 아이템을 먹으면, Then 기본 속도로 돌아간다.
- [ ] Given 막대 길이 + 효과 중에, When 막대 길이 + 아이템을 다시 먹으면, Then 남은 시간이 10초로 갱신된다.
- [ ] Given 점수 + 효과 중에, When 일반 블록이 깨지면, Then 200점이 오른다.
- [ ] Given 공이 여러 개일 때, When 공 하나만 막대 아래로 떨어지면, Then LIFE는 줄지 않는다.
- [ ] Given LIFE가 1일 때, When 마지막 공이 떨어지면, Then GAME OVER 화면에 최종 점수가 표시되고 space로 title에 돌아간다.
- [ ] Given 메탈 블록만 남았을 때, When 마지막 일반·강화 블록이 깨지면, Then 다음 스테이지가 시작된다.
- [ ] Given pause 상태일 때, When 시간이 흘러도, Then 공, 아이템, 아이템 타이머가 움직이지 않는다.
- [ ] Given 마우스를 움직인 뒤에, When 키보드 방향키를 누르면, Then 키보드가 막대를 제어한다.
- [ ] Given 막대 위에 공이 대기 중일 때, When 막대를 움직이면, Then 공이 막대를 따라 움직인다.
- [ ] Given 막대 길이 + 효과 중에, When LIFE를 잃으면, Then 막대 길이 효과는 남은 시간 동안 유지된다.
- [ ] Given 게임 중일 때, When ESC를 누르면, Then pause 메뉴가 열리고 다시 누르면 재개된다.
- [ ] Given 스테이지 1일 때, When 블록이 배치되면, Then 메탈·강화 블록은 없고 96칸 중 40~70%가 채워진다.
- [ ] Given 게임 중에 점수와 아이템 효과가 있을 때, When pause 메뉴에서 restart를 누르면, Then 1스테이지부터 점수 0, LIFE 3, 효과 없음 상태로 시작한다.
- [ ] Given 게임 중일 때, When 브라우저 탭이 비활성화되면, Then 자동으로 pause 된다.
- [ ] Given 막대 위에 공이 있을 때, When space를 누르면, Then 공이 위쪽 45도 방향으로 발사된다.
