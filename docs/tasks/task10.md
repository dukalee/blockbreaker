# Task 10: 사운드 엔진과 효과음

## 참조
- FR-27

## 선행 task
- Task 7, Task 9

## 구현 기능 목록
- Web Audio API 기반 오디오 모듈: AudioContext 생성, 마스터 GainNode (볼륨/음소거 제어 지점)
- 첫 사용자 입력(space) 이후 AudioContext 시작 (브라우저 자동 재생 정책 대응)
- OscillatorNode와 GainNode로 효과음 8종 합성: 공 발사, 벽·막대 충돌, 블록 파괴, 강화·메탈 블록 타격, 아이템 습득, LIFE 상실, 스테이지 클리어, 게임 오버
- 게임 이벤트에 효과음 연결 (각 이벤트 발생 지점에서 호출)
- 연속 충돌 시에도 소리가 겹쳐 끊기거나 터지지 않도록 처리

## 완성 조건
- [ ] 8종 효과음이 각 상황에서 재생되고 서로 구분된다.
- [ ] 첫 space 입력 전에는 오류 없이 무음이고, 이후 재생된다.
- [ ] 공 6개가 동시에 충돌해도 소리가 깨지거나 앱이 느려지지 않는다.
- [ ] 별도 음원 파일 없이 코드로만 소리가 난다.
- [ ] 마스터 GainNode 값을 바꾸면 모든 효과음 볼륨이 함께 바뀐다.
