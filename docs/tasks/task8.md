# Task 8: 아이템 드롭, 낙하, 습득

## 참조
- FR-12, FR-13, FR-29 (낙하 중인 아이템 유지)

## 선행 task
- Task 5, Task 7

## 구현 기능 목록
- 아이템 엔티티와 6종 타입 정의: 공 분산, 공 속도 +, 공 속도 -, 막대 길이 +, 막대 길이 -, 점수 +
- 블록이 완전히 깨질 때 20% 확률로 드롭, 종류는 6종 동일 확률 (확률은 상수로 조정 가능)
- 블록 위치에서 중력 가속으로 천천히 낙하
- 막대와 닿으면 습득(효과 적용 호출만 연결, 실제 효과는 Task 9), 화면 아래로 나가면 제거
- LIFE 상실, 스테이지 클리어 시에도 낙하 중인 아이템 유지
- 아이템 렌더링 (종류별 구분되는 아이콘/색)

## 완성 조건
- [ ] 블록을 깨면 약 20% 확률로 아이템이 나타나고, 6종이 고르게 나온다. (확률 로직은 단위 테스트로 검증)
- [ ] 아이템이 위에서 아래로 가속되며 천천히 떨어진다.
- [ ] 막대에 닿은 아이템은 사라지고 습득 이벤트가 발생한다.
- [ ] 막대를 놓친 아이템은 화면 아래에서 사라진다.
- [ ] LIFE를 잃거나 스테이지가 넘어가도 낙하 중인 아이템은 계속 떨어진다.
- [ ] 메탈 블록이나 첫 타격만 받은 강화 블록에서는 아이템이 나오지 않는다.
