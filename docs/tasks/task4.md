# Task 4: 블록과 점수

## 참조
- FR-5 (블록 충돌 반사), FR-7, FR-8, FR-9, FR-10, FR-11

## 선행 task
- Task 3

## 구현 기능 목록
- 블록 종류: 일반(1타), 강화(2타, 1타 후 모양 변화), 메탈(파괴 불가)
- 스테이지 생성 함수: 12열 x 8행 그리드(96칸)의 40~70%를 랜덤으로 채움. 종류 비율은 입력값(메탈%, 강화%)으로 받음 (스테이지별 비율은 Task 5에서 연결)
- 일반 블록 색상: 여러 색을 랜덤으로 사용
- 공-블록 충돌: 겹침이 더 적은 축으로 반사, 한 번에 여러 블록과 닿는 경우 처리
- 강화 블록은 첫 타격에서 남고 두 번째에 파괴, 메탈 블록은 항상 유지
- 점수: 블록이 완전히 깨질 때만 100점 (강화는 두 번째 타격에서)
- 파괴 가능한 블록이 최소 1개는 있도록 생성
- 블록 렌더링과 점수 상태 보관

## 완성 조건
- [ ] 스테이지 시작 시 96칸 중 40~70%에 블록이 랜덤으로 배치되고, 일반 블록은 여러 색이다.
- [ ] 일반 블록은 1번 맞으면 사라지고 100점이 오른다.
- [ ] 강화 블록은 1번 맞으면 모양이 바뀌고 점수는 오르지 않으며, 2번째에 사라지고 100점이 오른다.
- [ ] 메탈 블록은 공이 맞아도 깨지지 않고 공은 반사된다.
- [ ] 블록 모서리에 맞는 경우에도 공이 블록을 통과하거나 끼지 않는다.
- [ ] 블록 배치 비율·밀도, 충돌 축 판정, 점수 계산에 대한 단위 테스트가 통과한다.
